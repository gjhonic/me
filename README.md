## О проекте

Обычное CV — это список должностей и обязанностей. Это CV — небольшой
интерактивный мир в духе классических 8-bit платформеров, где:

- уровни — это разделы резюме (`WORLD 1-1`, `WORLD 1-2`, ...);
- по опыту работы и проектам можно кликнуть и открыть модалку с цифрами,
  визуализацией метрик и ключевыми результатами — тем, что обычно ищут HR;
- навыки открываются как блоки-«вопросики» — по одному за раз;
- страница встречает анимированным пиксельным экраном загрузки;
- а долистав футер до конца, можно поиграть в раннер в духе Chrome Dino —
  футер в буквальном смысле является землёй, по которой бежит герой.

Сайт статический, без сборки и фреймворков — специально, чтобы GitHub Pages
отдавал его мгновенно и без лишней инфраструктуры.

## Возможности

| Раздел | Что внутри |
| --- | --- |
| **Обо мне** | Краткое досье и факты в стиле игрового HUD |
| **Опыт работы** | Карточки-«миры» по местам работы, клик открывает модалку с анимированными счётчиками (модули, ТБ данных, менторство, интервью) |
| **Навыки** | Блоки-«вопросики», раскрываются по одному (аккордеон) |
| **Проекты** | RetroGame, RetroGameMobile, CITY//RUSH и продакшн-система SEVAND — тоже с модалкой и цифрами использования |
| **Образование** | Карточка вуза |
| **Контакты** | Email, Telegram, GitHub |
| **Футер-игра** | Мини-раннер: прыгай через противников, счёт и рекорд сохраняются в `localStorage` |

## Стек

- **Vanilla HTML / CSS / JavaScript** — без сборки, без зависимостей, без npm
- **Canvas 2D** — весь пиксель-арт мини-игры нарисован кодом (без спрайтов и картинок)
- **CSS custom properties** — единая ретро-палитра (Mario-like: небо, кирпич, монеты)
- Шрифт [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) для заголовков
- `IntersectionObserver` — анимации при скролле и включение управления игрой только когда футер виден
- `localStorage` — сохранение рекорда мини-игры

```
docs/                  # GitHub Pages сервит сайт из этой папки
├── index.html          # вся разметка: hero, опыт, навыки, проекты, модалки, футер-игра
├── favicon.svg
├── css/
│   └── style.css        # ретро-палитра, адаптивная вёрстка, стили модалок и прелоадера
└── js/
    ├── main.js           # прелоадер, навигация, reveal-анимации, счётчики, модалки, аккордеон навыков

```

## Запуск локально

Сайт полностью статический — достаточно любого HTTP-сервера:

```bash
cd docs
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Мини-игра в футере

Долистайте страницу до конца — футер становится игровым полем.

- **Space / ↑ / клик** — прыжок
- Скорость и частота препятствий растут со временем
- Рекорд (`HI`) сохраняется между визитами
